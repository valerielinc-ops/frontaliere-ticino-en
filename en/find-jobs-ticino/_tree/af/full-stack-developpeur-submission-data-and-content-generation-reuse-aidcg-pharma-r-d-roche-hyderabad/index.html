The Position Job description We are seeking a motivated Full Stack Developer with exposure to Generative AI technologies to join our team. The candidate will contribute to the development and enhancement of AI-powered applications using React, Python, AWS cloud services, and modern LLM frameworks. This role is ideal for engineers who have strong software engineering fundamentals and an interest in building cloud-native and AI-enabled applications.

Description of the area

Job Responsibilities

  • Develop and enhance React-based frontend applications.
  • Build and maintain backend APIs using Python and FastAPI.
  • Contribute to AWS-based serverless applications using Lambda and API Gateway.
  • Integrate AI/LLM services such as OpenAI, Claude, or AWS Bedrock into business workflows.
  • Support implementation of Retrieval Augmented Generation (RAG) solutions and vector search capabilities.
  • Work with databases such as PostgreSQL, DynamoDB, and S3.
  • Collaborate with data scientists and senior engineers to integrate AI models into applications.
  • Participate in CI/CD pipelines and application deployment activities.
  • Troubleshoot application issues and contribute to performance improvements.
  • Follow secure coding and cloud best practices.

Qualifications Education / Experience

  • Bachelor's or Master's degree in Computer Science, Engineering, or related field.
  • 1 to 5 years of software development experience.
  • Experience building web applications using modern frontend and backend technologies.
  • Exposure to cloud-native development and AI-powered applications is preferred.

Technical Skills

  • Frontend: React, TypeScript
  • Backend: FastAPI (Python), AWS Lambda, API Gateway (REST + WebSocket)
  • Search & Storage: DynamoDB, Aurora PostgreSQL
  • GenAI & RAG: LangChain, OpenAI, Claude, AWS Bedrock
  • DevOps: GitHub Actions

You Should Also Have

  • Strong programming skills in Python.
  • Experience with React-based application development.
  • Understanding of API development and integration.
  • Basic cloud development experience on AWS.
  • Exposure to Generative AI technologies and LLM-based applications.
  • Understanding of software engineering best practices.
