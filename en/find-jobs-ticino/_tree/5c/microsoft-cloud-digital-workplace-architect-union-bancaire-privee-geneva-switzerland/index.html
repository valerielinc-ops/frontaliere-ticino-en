Full description

  • Mission

Function purpose: The Microsoft Cloud & Digital Workplace Architect is responsible for defining, designing, and leading the implementation of enterprise cloud and workplace solutions across Microsoft Azure and Microsoft 365. This strategic and technical leadership role combines Cloud Architecture, Modern Workplace, Security, Identity, Collaboration, and Infrastructure expertise to deliver secure, scalable, resilient, and user-centric digital services. The Architect leads the cloud committee which represent an authority of approval for new cloud service adoption and deployment within the group

  • Main responsibilities

Cloud Strategy & Architecture

  • Define and maintain the enterprise Microsoft Cloud strategy and roadmap.
  • Design secure, scalable, highly available, and cost-effective cloud architectures.
  • Ensure cloud solutions align with business objectives, security requirements, and compliance standards.
  • Establish Azure Landing Zones and cloud governance models.

Digital Workplace Architecture

  • Define the Digital Workplace vision and architecture.
  • Design collaboration and productivity platforms using Microsoft 365.
  • Lead workplace transformation initiatives supporting hybrid and remote work.
  • Improve employee productivity and digital experience through innovative workplace services.

Identity, Security & Compliance

  • Architect enterprise identity and access management using Microsoft Entra ID.
  • Define and implement Zero Trust security principles.
  • Design Conditional Access, Identity Governance, MFA, and Privileged Access Management.
  • Establish security controls mastering: Microsoft Defender Suite, Microsoft Sentinel, Microsoft Purview, Data Loss Prevention (DLP), Information Protection.

Ensure compliance with industry regulations and corporate policies. Endpoint & Device Management

  • Define modern endpoint management strategy.
  • Lead Microsoft Intune initiative.
  • Implement: Windows Autopilot, Mobile Device Management (MDM), Mobile Application Management (MAM), Endpoint Security, Device Compliance Policies

Technical Leadership

  • Act as the senior technical authority for Cloud and Workplace technologies.
  • Lead architecture review boards and technical governance committees.
  • Define engineering standards and best practices.
  • Serve as escalation point for critical technical issues.

  • Endpoint Management: Microsoft Intune, Windows 11, Autopilot, Endpoint Analytics, Mobile Device Management
