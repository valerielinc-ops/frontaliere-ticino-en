Your role and responsibilities
We are seeking a Software Engineer with a proven track record in Desktop applications, preferably backed by a background in DevOps and Cyber Security. The successful candidate will play a crucial role in designing, developing, deploying, and maintaining cutting-edge applications within the Digital Agile Unit. This role specifically focuses on Desktop SW (Software) application.

The successful candidate will play a crucial role in designing, developing, deploying, and maintaining modern multiplatform desktop applications within the Digital Agile Unit, targeting both Windows PCs and Mac environments. This role focuses on digital products and software tools across desktop platforms, covering IoT connectivity, cloud platform integration, device interaction, data management, and reliable user-facing solutions for enterprise users. In addition, you will apply AI-assisted and agentic programming practices in daily development activities to improve productivity, code quality, testing, and technical documentation.

In this role, it is also essential to follow cybersecurity standards, apply appropriate security measures throughout the development process, and comply with ABB’s secure development lifecycle. These practices help ensure that the software released is highly reliable, robust, and secure.


The work model for the role is: Hybrid (#LI-Hybrid)

Key • Responsibilities:

  • Architecture & Development: Design and develop modern Windows desktop applications using Microsoft technologies such as .NET, C#, WPF, WinUI, Windows App SDK, and C++, delivering robust, maintainable, and user-friendly solutions.
  • Professional knowledge of the Microsoft .NET Framework, with in-depth expertise in C# and C++ programming languages for the design, development, and maintenance of desktop applications.
  • Modern Desktop Engineering: Apply contemporary desktop application patterns, including MVVM, dependency injection, modular architecture, asynchronous programming, and responsive UI design to ensure scalable and high-quality software.
  • System & Device Integration: Optimize software designs by identifying the most suitable services, architectural choices, and technical solutions, with a focus on seamless integration between desktop applications, smart devices, hardware, and IoT communication protocols.
  • AI-Driven Productivity & Agentic Engineering: Use AI-assisted coding tools such as GitHub Copilot and agentic workflows to support code generation, refactoring, automated testing, documentation, and code review, while maintaining human oversight and secure development practices.
  • Agile Collaboration: Apply Scrum methodology, including Epics, Features, User Stories, and Bugs, and actively collaborate with development, UX/UI, test, cybersecurity, and product teams within the Agile unit.
  • CI/CD & Automation: Implement and maintain CI/CD pipelines using tools such as Azure DevOps or GitHub Actions to support automated builds, testing, packaging, signing, and deployment of Windows desktop applications.
  • Software Excellence: Ensure software quality through code reviews, static code analysis, unit and integration testing, software metrics, and modern engineering practices aimed at building reliable and maintainable applications.
  • Security & Compliance: Implement cybersecurity measures by following the Security Development Lifecycle, secure coding standards, data protection practices, and defined security requirements throughout the development and delivery process.

• Qualifications for the role:

  • Degree: Bachelor’s or master’s degree in electronic engineering, Computer Science Engineering, Computer Science, or a related technical field.
  • Core Desktop Expertise: Solid experience in Windows desktop application development using .NET, C#, WPF, WinUI, Windows App SDK, and/or C++.
  • Modern Windows Technologies: Strong knowledge of modern Windows application architectures, UI frameworks, application lifecycle management, packaging, deployment, and integration with Windows services and APIs.
  • Architecture & Design Patterns: Good understanding of MVVM, Clean Architecture, dependency injection, asynchronous programming, multithreading, and event-driven design for desktop applications.
  • AI-Assisted Development: Hands-on experience with GitHub Copilot, Cursor, or equivalent AI-assisted coding tools and LLM-based agents to improve productivity, prototyping, testing, refactoring, and code reviews in a safe and controlled way.
  • DevOps & Cloud Integration: Familiarity with Azure, Azure DevOps, GitHub Actions, CI/CD pipelines, automated testing, release management, and integration with cloud services or RESTful APIs.
  • Device Connectivity: Experience with communication protocols and device integration, such as Modbus, TCP/IP, RS-485, Bluetooth Low Energy, Ethernet, or similar industrial and IoT connectivity technologies.
  • Cybersecurity: Strong understanding of secure coding practices, static analysis tools, secure data handling, authentication, encryption, and Security Development Lifecycle requirements.
  • Methodology: Hands-on experience with Agile/Scrum development methodologies.
  • Soft Skills: Innovative approach to problem-solving, strong communication skills, and a collaborative mindset.
  • Languages: Fluent in English and Italian.

Nice-to-Have:

  • Familiarity with agentic workflows for code automation, specification-to-code generation, and automated pull request review.
  • Experience with modern Windows deployment and packaging technologies, such as MSIX, ClickOnce, or enterprise software distribution tools.
  • Knowledge of cross-platform desktop frameworks or interoperability scenarios involving Windows, cloud services, and edge devices.
  • Familiarity with containerization, observability, logging, and monitoring tools for desktop-connected solutions.
