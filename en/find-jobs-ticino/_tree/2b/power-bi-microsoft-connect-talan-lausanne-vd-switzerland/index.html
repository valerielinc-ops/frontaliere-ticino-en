Full description

Responsibilities

  • Participate in the migration of Tableau reports and environments to Power BI / Microsoft Fabric .
  • Analyze the existing environment and contribute to defining migration strategies.
  • Prioritize the use of Direct Lake to limit duplications and optimize performance.
  • Use Import mode when technical constraints require an alternative approach.
  • Design and evolve Power BI / Fabric semantic models .
  • Work with existing SQL / Data Warehouse sources and environments.
  • Ensure the quality, performance and maintainability of the solutions developed.
  • Apply best practices for Git, versioning, CI/CD and development management .
  • Contribute to improving collaboration and governance practices within the team.
  • Participate in the testing, validation and production deployment phases.
  • Gradually support the migration of the various functional areas.

Desired profile

  • Significant experience as a Data Analyst / Power BI Expert .
  • Strong experience with Microsoft Power BI and Microsoft Fabric .
  • Very good command of semantic models and Power BI architecture.
  • Practical experience with Direct Lake and ideally migration scenarios to Fabric.
  • Good knowledge of SQL / Data Warehouse .
  • Proficiency in Git best practices and version control .
  • Experience in environments where governance and collaboration considerations are important.
  • Experience migrating from Tableau → Power BI is a real asset.
  • Ability to work independently in a complex, deadline-constrained context.
  • Excellent professional demeanor, ability to communicate with different stakeholders and work as part of a team.
  • A proven level of expertise is expected.
