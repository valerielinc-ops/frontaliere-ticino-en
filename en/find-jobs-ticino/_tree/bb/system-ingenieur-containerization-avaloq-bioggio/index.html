System Engineer (Containerization) — Avaloq

This position is no longer active. Below you'll find the original details and other open positions.

Full description

We are looking for a System Engineer with strong Kubernetes expertise to join our project delivery team. This role is focused on designing, implementing, and delivering Kubernetes-based solutions for client projects — not on day-to-day operations or production support. You will work alongside project managers, architects, and developers to bring cloud infrastructure projects from concept to deployment. Your key tasks

  • Design and implement Kubernetes cluster architectures for new client projects (on-premise, cloud, or hybrid)
  • Build and deploy containerized application platforms using Kubernetes, Helm, and Operators
  • develop infrastructure-as-code templates (Terraform, HCL) for repeatable Kubernetes deployments
  • Configure cluster security, networking (CNI), storage (CSI), and access controls (RBAC) for project environments
  • Integrate Kubernetes with CI/CD pipelines and support application teams during project delivery
  • Collaborate with solution architects to define cloud infrastructure strategies aligned with project requirements
  • Create technical documentation, architecture diagrams, and implementation guides for project handover
  • Perform prototype and pilot deployments to validate Kubernetes solutions before full-scale implementation
  • Troubleshoot project-level issues during deployment and configuration phases
  • Support client workshops and technical presentations to demonstrate Kubernetes capabilities

Qualifiche

  • 3+ years of experience in system engineering, cloud infrastructure, or project delivery roles
  • Hands-on experience designing, building, and operating Kubernetes clusters in enterprise environments
  • Strong knowledge of container technologies and orchestration platforms (Docker, containerd, Kubernetes)
  • Proficiency in Linux environments (RHEL, CoreOS) and automation scripting (Bash, Python, or Go)
  • Experience with Infrastructure as Code (Terraform/HCL) and Kubernetes automation
  • Familiarity with cloud platforms such as Oracle Cloud Infrastructure (OCI), AWS, or Azure
  • Experience with CI/CD tools and DevOps practices (GitLab CI, Jenkins)
  • Knowledge of monitoring, observability, and container platform operations
  • Certified Kubernetes Administrator (CKA) or CKAD certification
  • Experience delivering infrastructure or cloud transformation projects in regulated enterprise environments
  • Strong analytical, stakeholder management, and project collaboration skills
  • Excellent communication skills in English
