ITOT Singapore group manages Process Controls Systems (PCS), Information Management System (IMS), Building Automation Systems (BAS), Manufacturing Execution System (MES) and a number of GMP and non-GMP computer-based systems.

This role is a key member of MES & Control Systems group handling all systems-related aspects of the PCS, IMS, BAS and MES, Core responsibilities include managing servers, network hardware, systems security and user management, database management, Data Integrity and Computer System Validation (CSV) deliverables.
