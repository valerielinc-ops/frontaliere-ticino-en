The Position Fullstack Developer We are looking for a Fullstack Developer with strong hands-on experience in building scalable web applications and implementing reliable automation testing practices. Role Overview The candidate will be responsible for designing, developing, testing, and maintaining web-based applications. They should be capable of working independently as well as collaboratively with product, design, QA, and engineering teams. A strong quality mindset is essential, with experience in creating automated tests for frontend, backend, and API layers. Key Responsibilities

  • Develop and maintain fullstack web applications using modern frontend and backend technologies.
  • Build responsive, reusable, and maintainable frontend components.
  • Design, implement, and maintain backend services, APIs, and database integrations.
  • Create and maintain automated test suites for UI, API, integration, and regression testing.
  • Collaborate with QA and engineering teams to improve test coverage and release quality.
  • Integrate automated tests into CI/CD pipelines.
  • Participate in code reviews, technical discussions, and architecture decisions.
  • Troubleshoot, debug, and resolve application issues across the stack.
  • Ensure code quality, performance, security, and scalability best practices are followed.
  • Contribute to documentation for technical designs, APIs, and testing processes.

Required Skills and Experience

  • Strong experience as a Fullstack Developer .
  • Proficiency in frontend technologies such as JavaScript, TypeScript, React, Angular, or Vue.js .
  • Backend development experience with technologies such as Node.js, Java, Python, .NET, or similar .
  • Experience designing and consuming RESTful APIs or GraphQL services.
  • Solid understanding of databases such as PostgreSQL, MySQL, MongoDB, or similar .
  • Hands-on experience with automation testing tools such as Playwright, Cypress, Selenium, Jest, Mocha, JUnit, PyTest, or similar .
