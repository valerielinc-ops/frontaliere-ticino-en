The Position We are looking for an Engineering Student or Recent Graduate (Computer Science, Telecommunications, Software, or similar) to join our Quality and Development team. This opportunity is perfect if you want to learn how quality is managed in a complex product, combining test management (TestOps) with more technical infrastructure and automation tasks (DevOps/QA). You will work hand-in-hand with our Test Manager and the technical engineering team. Primary Responsibilities and Tasks Support for Test Management and Operations (50%)

  • Results Management: Upload and centralize automated test results in Allure TestOps.
  • Dashboards and Reporting: Create and maintain visualization dashboards to track key quality metrics (quality gates, coverage, test execution).
  • Operational Tracking: Review and update the status of tasks, bugs, and user stories in JIRA to ensure complete coverage and traceability.
  • General Support: Assist the Test Manager in organizing, reviewing, and tracking test plans.
  • Test Case Execution: Execute and report manual test cases based on product needs and planning.

Technical Support and QA Infrastructure (50%)

  • Tool Integration: Implement and configure plugins and extensions in code repositories (e.g., reporting in Allure).
  • Repository Migration: Collaborate in the migration, maintenance, and reorganization process of code/test repositories.
  • Basic Automation: Assist in setting up simple CI/CD pipelines for automated test suite execution.

Profile Requirements

Education

  • Final-year student or recent graduate in Computer Science, Software Engineering, Telecommunications, or a related technical degree (possibility of signing an internship agreement with a university/school).

Basic Knowledge

  • Experience with version control using Git and platforms like GitHub/GitLab.
  • Interest in or basic understanding of QA/Testing concepts (differences between unit, integration, and E2E tests).
  • Familiarity with a project management tool (Jira, Trello, Azure DevOps).

Soft Skills

  • Strong organizational skills, attention to detail, and proactivity.
  • Good communication skills and team player mindset.
  • Technical curiosity and eagerness to learn modern QA tools (TestOps).

Nice to Have (Bonus Points!)

  • Previous experience using Allure / Allure TestOps or reporting tools.
  • Basic knowledge of CI/CD (GitHub Actions, GitLab CI, Jenkins).
  • Technical English proficiency (reading documentation and navigating tools in English).
