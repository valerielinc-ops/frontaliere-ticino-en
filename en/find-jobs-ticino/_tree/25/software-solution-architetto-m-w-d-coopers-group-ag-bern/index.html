Full description

For our customers from the public sector, we are looking for an experienced Software & Solution Architect to design and implement a modern, database-supported software solution. In this versatile role, you take on the technical architecture as well as the hands-on development and integration of a cross-platform application. You combine your expertise in software engineering, full-stack development and DevOps to realize a scalable, secure and long-term maintainable solution.

Your tasks

  • Conception and implementation of the overall and detailed architecture of a cross-platform software solution with local and containerized operating variant
  • Development and integration of intuitive user interfaces (GUI) for local applications and web applications as well as implementation of server-side business logic
  • Design and implementation of database solutions based on PostgreSQL, SQLite or comparable technologies including data management, versioning and traceability
  • Implementation of user and role management, authorization concepts and import, export and management functions
  • Establishment and further development of containerized infrastructures with Docker and Kubernetes including CI/CD pipelines, automated testing and deployment processes
  • Design and integration of API interfaces and optional ETL/ELT processes for connecting external data sources
  • Ensuring cross-platform use under Windows and Linux as well as compliance with security, classification and open source license requirements
  • Implementation of unit and integration tests and preparation of technical documentation, operating instructions and user manuals

Your profile

  • Completed training in computer science (HF, FH, university) or comparable qualification with in-depth practical experience
  • Several years of experience in software and solution architecture as well as in the conception and development of complex software solutions
  • In-depth knowledge in full-stack development, especially in the implementation of web applications, user interfaces and backend systems
  • Practical experience with relational databases such as PostgreSQL and SQLite, and ideally with database-based management interfaces such as Baserow
  • Good knowledge of containerization and orchestration with Docker, Docker Compose and Kubernetes
  • Experience with DevOps practices, Git, CI/CD pipelines, automated testing, monitoring and logging
  • Knowledge of API integration and data processing, ideally with Python, ETL/ELT processes and Apache Airflow
  • Familiarity with open source technologies and experience in developing cross-platform applications for Windows and Linux
  • Independent, structured and solution-oriented working method with a pronounced hands-on mentality
  • Very good knowledge of German and good knowledge of English for the technical documentation
  • Clean Leumund is mandatory
