Main responsibilities

  • As a Senior Cybersecurity Engineer (Development Frameworks & Automation), your key responsibilities and priorities will include:
  • Architecture & Design Baseline: Collaboratively building, designing, adapting, and standardizing internal security development frameworks and engineering practices, establishing consistent coding guidelines and architectural baselines across the product area.
  • Structural Engineering & Guardrails: Contributing to structural engineering decisions by providing software design insights, defining secure control guardrails, and creating code abstraction layers to streamline the deployment of network controls.
  • Product Lifecycle & Custom Automation: Driving code development to improve infrastructure services by writing robust scripts, modular automation blocks, and custom APIs to seamlessly scale connectivity safeguards.
  • CI/CD Integration: Guiding technical implementations through all stages of the software engineering lifecycle—from defining structured automation frameworks to deploying tested, scalable security features using CI/CD.
  • Operational Excellence & Code Quality: Standardizing core development workflows (such as version control frameworks, comprehensive testing, and peer review practices) to guarantee the reliability and code quality of live infrastructure configurations.
  • Cross-Functional Collaboration: Working cross-functionally with internal stakeholders and platform teams to measure, monitor, and continuously improve the reliability, maintenance, and automated health checking of network infrastructure code.
  • Continuous Improvement of Capabilities: Supporting the end-to-end delivery, design, and maintenance of technologies protecting Roche networks and the Internet (on-prem and cloud), including Internet Security Stack, DDoS Protection, Site-to-Site Connectivity (VPN), Network Access Control, and Deep Packet Inspect
