Your role and responsibilities
We are seeking an experienced Senior Software Engineer with a strong background in modern cross-platform mobile development, specifically leveraging Kotlin Multiplatform (KMP) and Compose Multiplatform, backed by experience in DevOps, Azure, and Cyber Security.

The successful candidate will play a crucial role in designing, developing, deploying, and maintaining cutting-edge applications within the Digital Agile Unit. This role focuses on digital products, covering IoT, cloud platforms, SW Tools, APPs, and Data Management In addition, you will apply AI-assisted and agentic programming practices in daily development activities.

In this role, it is also essential to follow cybersecurity standards, apply appropriate security measures throughout the development process, and comply with ABB’s secure development lifecycle. These practices help ensure that the software released is highly reliable, robust, and secure.

The work model for the role is: Hybrid (#LI-Hybrid)

Key • Responsibilities:

  • Architecture & Development: Designing cross-platform mobile applications using Kotlin Multiplatform (KMP) and Compose Multiplatform, optimizing code sharing across Android and iOS without compromising native performance or UI/UX fidelity.
  • AI-Driven Productivity & Agentic Engineering: Championing the adoption of AI pair-programming tools (e.g., GitHub Copilot) and agentic workflows to streamline code generation, automated unit testing, refactoring, and technical documentation while enforcing human-in-the-loop validation and security.
  • System & Device Integration: Optimizing designs by identifying the best technical solutions, including services, architectural choices, and technical details. Emphasis is placed on seamless integration between software applications and smart devices/hardware via IoT protocols (e.g., Bluetooth LE, MQTT).
  • Agile Collaboration: Applying Scrum methodology (Epics, Features, User Stories, Bugs). Actively participating in Scrum ceremonies and collaborating closely with cross-functional development, UX/UI, and test teams within the Agile unit.
  • CI/CD & Automation: Implementing and maintaining modern CI/CD pipelines (e.g., Azure DevOps, GitHub Actions) tailored for multiplatform targets to ensure efficient release management, automated UI/unit testing, and reliable software delivery.
  • Software Excellence: Ensuring code quality by applying modern architectural patterns (MVI/MVVM, Clean Architecture, Dependency Injection via Koin/Dagger), performing rigorous code reviews, conducting static code analysis, and leveraging static analysis tools (e.g., Detekt, SonarQube).
  • Security & Compliance: Implementing cybersecurity measures by following the Security Development Lifecycle (SDL), ensuring robust data encryption at rest and in transit, secure storage (Keychain/EncryptedSharedPreferences), and meeting defined security requirements throughout development.
  • Local & Cloud Data Management: Designing and optimizing local persistence solutions (e.g., Room, SQLDelight) and managing seamless integration with cloud backends and RESTful/GraphQL APIs.

• Qualifications for the role:

  • Degree: Bachelor or master’s degree in electronic/computer science engineering, Computer Science, or a related technical field.
  • Core Mobile Expertise: Solid experience with Kotlin, Kotlin Multiplatform (KMP), and Compose Multiplatform (Declarative UI) for iOS/Android target execution.
  • AI-Assisted Development: Hands-on experience using GitHub Copilot, Cursor, or equivalent AI-assisted coding tools / LLM agents to accelerate software delivery, prompt-driven prototyping, and code reviews safely and securely.
  • Asynchronous & Reactive Programming: Strong knowledge of Kotlin Coroutines and Flow for concurrent state and stream management.
  • Architecture & Libraries: Deep understanding of modern Android/KMP architecture principles, lifecycle management, state handling, and dependency injection frameworks (e.g., Koin).
  • DevOps & Cloud Integration: Familiarity with cloud environments (particularly Azure) and experience setting up CI/CD pipelines for mobile delivery.
  • API & Connectivity: Hands-on experience with RESTful APIs, modern networking libraries (e.g., Ktor, Retrofit), and IoT device communication protocols (e.g., BLE, Wi-Fi provisioning).
  • Cybersecurity: Strong understanding of mobile security best practices, static analysis tools, and secure data handling under SDL protocols.
  • Methodology: Hands-on experience with Agile/Scrum development methodologies.
  • Soft Skills: Innovative approach to problem-solving, strong communication skills, and collaborative mindset.
  • Languages: Fluent in English and Italian.

Nice-to-Have:

  • Familiarity with agentic workflows for code automation, spec-to-code generation, and automated PR review bots.
  • Familiarity with Swift/Swift UI for platform-specific iOS bridge integrations.
  • Experience with local database frameworks suitable for KMP (e.g., Room KMP, SQL Delight).
  • Familiarity with containerization (Docker) and monitoring tools.
