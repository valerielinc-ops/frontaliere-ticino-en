Role overview

The Image Processing Engineer is a technical contributor within the Machine-Readable Features Laboratory , supporting the development, integration, validation, and optimization of image processing and computer vision algorithms used in machine-readable authentication and traceability systems.

The role covers a broad range of technologies including image analysis, machine vision, computer vision, optical sensing, signal processing, and machine learning techniques applied to advanced security features.

The position combines algorithm development, software implementation, data analysis, system integration, and experimental validation in close collaboration with multidisciplinary teams including optics, electronics, chemistry, software engineering, and data science.
