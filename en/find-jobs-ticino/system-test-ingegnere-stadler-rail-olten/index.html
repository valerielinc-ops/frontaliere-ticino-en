Description

PROFILE

  • Completed studies in electrical engineering, computer science, systems engineering or comparable technical training
  • Experience in system tests, ideally in safety-critical systems
  • Knowledge of test methodology, test automation and test management
  • Experience with requirements engineering tools and programming languages (Python and/or C++), experience with real-time controls
  • Understanding safety-related standards (EN 50126, EN 50129, EN 50716/50128) is an advantage
  • Very good German skills (C1), good English skills TASKS
  • Responsible for the planning, implementation and documentation of system tests and subsystem tests for the EUROLOCKING electronic signalling system
  • Ensuring functional and safety-relevant system and customer requirements
  • Creation of test concepts, test plans and test cases as well as definition of test strategies
  • Performing manual and automated tests and analysing test results
  • Development and maintenance of automated test scripts and test frameworks
  • Preparation of test reports, error logs and evidence for approval
